# Flick Panel 0.1.85

- Live cameras use native Home Assistant WebRTC where available, with optional go2rtc talkback and HLS video fallback. Talk and End call keep the live video session open.
- Camera tiles can show the last saved preview after an app restart or during an outage. The live viewer adds configurable camera actions, starts camera sound when available, and keeps the microphone off until Talk.
- The camera tile and viewer now use the same stream selection when a camera has a separate live feed.
- Room setup can search hidden controls and add fans, covers, selectors, and number controls. A Fan tile uses the speed and power controls its device reports. A Percentage tile works with batteries, humidity, storage, and other 0–100% sensors.
- Add tile gives the picker more room on tablets and wraps category filters on smaller screens. An Apps action in the header opens the shortcut picker.
- The dashboard and screensaver have separate brightness settings. Home Assistant can override the dashboard level and read the brightness in use.
- Settings stay open after saving. Tile sizes, light controls and screensaver timing use the same list controls, and short displays have side navigation to leave more room for content.
- Shopping lists, calendars, and the text reader share the media player's top-right Close button.
- Smaller APKs are available for individual Android processor types. Choose the universal APK if you are unsure.

Requires Android 9 or later. See the [user manual](../manual.md) for setup, room layouts, backups, and Home Assistant actions.
