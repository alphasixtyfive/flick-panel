# Flick Panel 0.1.94

- Open PIN-protected **Settings** from the dashboard. Tap **Retry** when Home Assistant is offline or **Replace token** when it rejects your credentials.
- Use **Preview layout** in Favourites to see how your draft fits on the tablet and which tiles appear on each page before saving.
- First-time setup shows where to create a Home Assistant access token and marks invalid entries beside the relevant fields.
- Device controls wait for fresh readings when Home Assistant reconnects. Cached numeric readings are marked **Last reported** while the panel is disconnected.
- The offline person map lays out fewer street labels as you pan and zoom. The dashboard and idle clocks pause updates when the app is off screen.

Requires Android 9 or later. To update from Flick Panel, open **Settings → Panel → Updates**. For a manual install, choose the universal APK if you are unsure which version you need.
