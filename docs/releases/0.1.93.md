# Flick Panel 0.1.93

- Compact control tiles group the name and state together, with icons that follow the tile's colours. You can choose an icon for supported tiles.
- A vacuum tile opens a full-screen map, battery reading and room checklist. Select the rooms to clean and use the controls supported by your vacuum.
- Gate tiles and nearby camera previews can share a section on wide Favourites layouts. A linked timer can show the progress of an action such as a hot-water boost.
- Home alerts show a count when the source supplies a list of issues. Tap the alert to see the entries.
- Music, shopping lists, calendars and maps use more consistent controls and spacing. Compact music tiles show playback state alongside the track.
- Check for updates from **Panel → Updates** in setup. The app downloads the matching APK and opens Android's installer for confirmation.

Requires Android 9 or later. Choose the universal APK if you are unsure which version to install.
