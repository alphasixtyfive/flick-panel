# Flick Panel screenshots

The gallery shows Flick Panel 0.1.92 with sample readings, room labels, appointments and media details. The Favourites and intercom examples use the app’s Compose controls and public-domain stills. The room, media, agenda and photo clock screens were captured from the released app on Android. Artwork for the music player and photo clock comes from [Flick TV’s bundled wallpapers](https://github.com/alphasixtyfive/flick-tv/tree/main/app/src/main/res/drawable-nodpi).

| Screen | What it shows |
| --- | --- |
| [Favourites](favourites.png) | See a camera preview, light controls, power and humidity graphs, and an alert. |
| [Rooms](rooms.png) | Worktop lights, thermostat, blind, fan and a scene grouped under Kitchen. |
| [Music player](music-player.png) | Artwork, playback position and transport controls for the selected Home Assistant speaker. |
| [Music library](music-library.png) | Browse albums, artists and playlists from a player that supports browsing. |
| [Shopping list](shopping-list.png) | Check off groceries from a shared Home Assistant to-do list. |
| [Calendar](calendar.png) | See upcoming events grouped by day. |
| [Photo clock](photo-clock.png) | A photo album, the time and a short message from Home Assistant. |
| [Intercom](../intercom.md) | See the full-screen camera with Talk, live status and nearby controls. |
| [Appearance](appearance.png) | Colour schemes, higher contrast and reduced motion. |
